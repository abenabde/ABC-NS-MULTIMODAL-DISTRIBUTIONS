# ABC-NS-MULTIMODAL-DISTRIBUTIONS
A likelihood-free sampler called ABC-NS-MM for handling multi-modal posterior distributions is introduced.
Title of the paper: 

Model updating via an efficient approximate Bayesian method for multi-modal (posterior) distributions (submitted to MSSP journal)
